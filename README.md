## 维护与开发

<details>
<summary><strong>仓库结构、维护与校验</strong></summary>

每个角色独立维护，`AGENT.md` 是唯一人设内容源。头像和技能引用保留稳定标识。修改人设时编辑角色目录中的文件；修改名称、简介、头像或技能引用时更新目录元数据。

```text
agents/
  personal-task-planner/
    AGENT.md
  business-writer/
    AGENT.md
catalog/v1/employees.json   # 角色元数据与技能引用
assets/agents/             # 角色头像
```

技能通过 [zbwork/skills](https://github.com/zbwork/skills) 的 `skill_uuid` 引用，不在本仓库复制技能内容。

**校验内容**

```sh
python3 scripts/build.py --skills-catalog ../skills/catalog/v1/skills.json --check
```

PR CI 检查角色完整性、图片摘要与技能引用。`main` 推送或手动运行 **Deploy Pages**，会从 `AGENT.md` 生成客户端目录，部署至 [官方数字员工资源](https://zbwork.github.io/agents/)。客户端匿名读取 `catalog/v1/employees.json` 和 `assets/` 头像。先部署技能库，再部署数字员工仓库；不创建 Release 或标签。

</details>
